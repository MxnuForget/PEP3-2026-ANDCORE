# Evidencias del trabajo con Raspberry Pi

En esta carpeta se encuentran las fotografías tomadas durante el proceso de preparación y configuración de nuestra Raspberry Pi 4 de 4 GB.

Las imágenes muestran parte del trabajo realizado, desde la instalación del sistema operativo y la configuración de la conexión SSH hasta la preparación del entorno de Python y la implementación del sistema de refrigeración con ventilador y disipadores.
